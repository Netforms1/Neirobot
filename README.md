# Neirobot

Telegram-бот на базе OpenAI GPT — универсальный ИИ-помощник, отвечающий на любые вопросы и помогающий с любыми задачами (код, тексты, переводы, идеи, расчёты и т.д.).

## Возможности

- Полностью кнопочный интерфейс с эмодзи
- 7 текстовых режимов + 🎨 генерация изображений (DALL·E)
- Красивое форматирование ответов: **жирный**, *курсив*, `код`, блоки кода с подсветкой, > цитаты, списки, заголовки
- В каждом режиме — свой system prompt, заточенный под задачу
- Контекст разговора (последние сообщения помнятся)
- Кнопка «🔄 Сбросить диалог» для очистки контекста
- Автоматическое разбиение длинных ответов под лимит Telegram
- Индикатор «печатает...» / «отправляет фото» во время генерации

## Установка

```bash
git clone https://github.com/netforms1/neirobot.git
cd neirobot
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

## Настройка

В файле `.env` укажите:

- `TELEGRAM_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `OPENAI_API_KEY` — ключ от [platform.openai.com](https://platform.openai.com/api-keys)
- `OPENAI_MODEL` *(опционально)* — текстовая модель, по умолчанию `gpt-4o-mini`
- `IMAGE_MODEL` *(опционально)* — модель для генерации фото, по умолчанию `dall-e-3`
- `IMAGE_SIZE` *(опционально)* — размер генерации, по умолчанию `1024x1024` (поддерживаются `1024x1024`, `1792x1024`, `1024x1792`)
- `MAX_HISTORY` *(опционально)* — сколько пар сообщений хранить в контексте, по умолчанию `20`

## Запуск

```bash
python bot.py
```

После запуска напишите боту в Telegram `/start`.

## Управление

| Кнопка / команда   | Действие                          |
|--------------------|-----------------------------------|
| `/start`           | Запуск бота, показ меню           |
| Режим (любой)      | Переключение в специальный режим  |
| `Сбросить диалог`  | Очистить историю                  |
| `Помощь`           | Справка                           |
